# Победи дракона — Ульяновск

Игра-табло для офисного экрана: герои шести групп филиала бьют пятиглавого дракона, каждый раз когда в таблице продаж появляется оплата. Каждый из пяти равных дневных планов недели (20 / 40 / 60 / 80 / 100 %) отрубает дракону голову; на 100 % — победа. Лидер филиала болеет за всех.

Это ответвление игры [«Отделы против дракона»](https://github.com/KonturProject/sales-vs-dragon) (Москва): механика и код те же, отличаются герои, фон, группы и свой бэкенд.

- Игра: https://konturproject.github.io/sales-vs-dragon-ulyanovsk/
- Админка (PIN): https://konturproject.github.io/sales-vs-dragon-ulyanovsk/admin.html

## Что умеет админка

План недели · просмотр таблицы продаж · внесение оплаты (она же запускает удар героя на экранах) · **импорт выгрузки** «Детальные данные по оплаченным счетам» (.xlsx разбирается в браузере, заменяет оплаты за период файла; после загрузки герои бьют по очереди) · **выбор героев** для каждой группы и лидера (30 персонажей) и **имена РГ** на табличках групп — замена на экранах за ~15 секунд · запуск анимаций (удар, падение, рычание, конфетти) · смена PIN.

## Группы

В таблице (лист `Sales`, колонка `ROP`) используются короткие коды: `ВШ1`, `ВШ4`, `ВШ5`, `ВШ6`, `ВШ9`, `ВШ10`.
Полные названия из CRM (`АП_НП_ОУ_Ульяновск_ВШ6_ГБ` и т. п.) тоже понимаются — по номеру «ВШ<число>» (`game/src/game/config/ropMapping.json`, `game/src/game/systems/Groups.ts`).
У каждой группы на сцене табличка «ВШ1 • Измайлова И.» (у заднего ряда над головой, у переднего под ногами), то же в рейтинге слева сверху; РГ меняются в админке, вкладка «Герои».

## Команды

Из папки `game/`:

```bash
npm install
npm run dev                 # локально, http://localhost:8080
npm run build               # сборка в game/dist
npm run deploy              # сборка + публикация на GitHub Pages
npm run test:backend        # тесты Code.gs на имитации сервисов Google
npm run mock-backend        # Code.gs локально на :8787 (PIN 1234); игру/админку направить: ?backend=http://localhost:8787/exec
npx tsc --noEmit -p tsconfig.json
```

## Бэкенд

Google Apps Script + таблица «победи дракона» — см. [apps-script/README.md](apps-script/README.md). PIN админки хранится только в свойствах скрипта (хеш), в репозитории его нет.
