# Победи дракона — Ульяновск

Игра-табло для офисного экрана: герои шести групп филиала бьют пятиглавого дракона, каждый раз когда в таблице продаж появляются оплаты. **Считаются штуки оплат, а не деньги**: план недели — число оплат, на экране «14 / 60 оплат». Каждый из пяти равных дневных планов недели (20 / 40 / 60 / 80 / 100 %) отрубает дракону голову; на 100 % — победа. Лидер филиала болеет за всех.

Это ответвление игры [«Отделы против дракона»](https://github.com/KonturProject/sales-vs-dragon) (Москва): механика и код те же, отличаются герои, фон, группы и свой бэкенд.

- Игра: https://konturproject.github.io/sales-vs-dragon-ulyanovsk/
- Админка (PIN): https://konturproject.github.io/sales-vs-dragon-ulyanovsk/admin.html
- Оплаты группы — страница для руководителей групп (свой PIN у каждого РГ): https://konturproject.github.io/sales-vs-dragon-ulyanovsk/rg.html

## Что умеет админка

План недели (в оплатах) · просмотр таблицы продаж · «Внести оплату» — тот же счётчик, что у РГ, для любой группы и дня (рост числа запускает удар героя на экранах) · **импорт выгрузки** «Детальные данные по оплаченным счетам» (.xlsx разбирается в браузере, один счёт — одна оплата, счета дешевле 100 ₽ не считаются; заменяет оплаты за период файла; после загрузки герои бьют по очереди) · **выбор героев** для каждой группы и лидера (30 персонажей) и **имена РГ** на табличках групп — замена на экранах за ~15 секунд · запуск анимаций (удар, падение, рычание, конфетти) · смена PIN · **PIN-коды руководителей групп** (создаются случайно, показываются один раз).

## Страница руководителей групп

`rg.html` — одна функция: сколько оплат у своей группы за день. Группу страница узнаёт по PIN (у каждого из шести РГ свой, их создаёт админка на вкладке «PIN-код»). РГ выбирает день текущей недели (до сегодня), видит число оплат группы на этот день, меняет его кнопками «−» / «+» и нажимает «Сохранить · было 2, станет 3». Число попадает в ту же таблицу; если выросло — герой группы бьёт дракона. Импорт выгрузки за те же дни потом заменит эти числа счетами из CRM; число, сохранённое после импорта, заменит счета своего дня (последнее слово — за тем, кто сохранил позже).

## Группы

В таблице (лист `Sales`, колонка `ROP`) используются короткие коды: `ВШ1`, `ВШ4`, `ВШ5`, `ВШ6`, `ВШ9`, `ВШ10`.
Полные названия из CRM (`АП_НП_ОУ_Ульяновск_ВШ6_ГБ` и т. п.) тоже понимаются — по номеру «ВШ<число>» (`game/src/game/config/ropMapping.json`, `game/src/game/systems/Groups.ts`).
У каждой группы на сцене табличка «ВШ1 • Измайлова И.» (у заднего ряда над головой, у переднего под ногами), то же в рейтинге слева сверху; РГ меняются в админке, вкладка «Герои».

## Команды

Из папки `game/`:

```bash
npm install
npm run dev                 # локально, http://localhost:8080
npm run build               # сборка в game/dist
npm run deploy              # сборка + публикация на GitHub Pages
npm run test:backend        # тесты Code.gs на имитации сервисов Google
npm run mock-backend        # Code.gs локально на :8787 (PIN 1234); игру/админку направить: ?backend=http://localhost:8787/exec
npx tsc --noEmit -p tsconfig.json
```

## Бэкенд

Google Apps Script + таблица «победи дракона» — см. [apps-script/README.md](apps-script/README.md). PIN админки хранится только в свойствах скрипта (хеш), в репозитории его нет.
